Your terminal, organized

Every tool.
One terminal.

ntc is a multi-tool shell for navigation, projects and everyday work: savepoints, aliases, task running, file exploring, an editor, a system monitor, package management and more — all in one binary.

Download for Windows x64 Terminal install

Windows 10/11 · free & open source · MIT

Windows Linux macOS Android · Termux arm64
~/ — install ntc
$ npm install -g @nuengcoder/ntc

npm works on Windows, Linux, macOS and Termux arm64. pip covers Windows x64, Linux x64 and macOS.

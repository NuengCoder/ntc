导航命令：
  cd <路径>                                导航到目录
  cd to <tp名称>                           传送到已保存的传送点
  gos                                    列出子目录并选择一个
  gosc                                   连续导航（0退出，v/s/vs查看）
  godrive                                列出并选择Windows驱动器
  back [n]                               返回父目录（或n层）
  fgo <模式> [-d <n>]                      查找文件，导航到所选文件的父目录
  where [<程序>]                           显示ntc位置信息，或在PATH中查找程序
示例：
    cd src                                 # 导航到 src 目录
    back                                   # 返回父目录
    gos                                    # 交互式子目录选择
    cd to web                              # 传送到 'web' 保存点
    where git                              # 在PATH中查找 git 的位置

配置命令：
  config output [路径]                     显示/设置输出路径
  config depth [n]                       显示/设置最大深度（1-20）
  config linenumbers on|off              显示/设置行号
  config color on|off                    显示/设置颜色输出
  config threads [n]                     显示/设置线程数
  config history [on|off|路径]             显示/设置历史记录
  config autosuggest on|off              显示/设置自动建议（幽灵文本）
  config git ON|OFF                      启用/禁用 git 集成（提示符和符号）
  config dir_view ON|OFF                 在shell中显示/隐藏目录树
  config watch on|off                    启用/禁用文件监视器
  config watch trigger <别名>              文件监视器触发时自动运行别名
  config watch trigger off               禁用自动运行
  config watch limit <数量>                监视器更改框中显示的行数
  wi [路径]                                实时文件更改流（q=退出）
  config qsc "#c 0"                      设置QSC全局热键
  config qsc off                         禁用QSC热键
  config lang [语言]                       显示/设置界面语言
  showcg                                 显示当前配置概览
  opencg                                 在编辑器中打开 config.toml
  resetcg                                重置配置为默认值（可选备份）
  restorecg                              从备份恢复配置
  local init                             创建 ntconfig.toml 模板（已注释）
  local deinit                           从当前目录删除 ntconfig.toml
  local help                             显示本地命令用法
  showenv                                显示环境变量（前5个PATH条目）
  showenv --all                          显示所有PATH条目
  showenv -d <n>                         显示前n个PATH条目
示例：
    config output ~/Desktop                # 设置输出路径到桌面
    config depth 3                         # 设置最大深度为 3
    config color ON                        # 启用彩色输出
    config threads 8                       # 设置线程数为 8
    showcg                                 # 显示当前配置概览

编辑器命令：

    ne main.rs                             # 在编辑器中打开 main.rs
    ne src/main.rs:42                      # 在 42 行打开 main.rs
    ne --init a.py b.html -I a.py          # 创建模板并打开 a.py
    ne --hyper myproject --lang c          # 创建 C 语言 hyper 项目

运行别名命令：
  ral add <名称> "<命令>"                    创建别名
  ral add <名称>(x) "<命令>"                 创建带参数的别名（使用 $x）
  ral add <名称>({x=a,e=txt}) "<命令>"       带默认值的别名
  ral add <名称>(x[],y) "<命令>"             带数组参数的别名
  ral add <名称>(x) "echo $*{x}"           捕获一个参数（保留空格，去除引号）
  ral edit <名称> "<命令>"                   更新别名
  ral rnm <旧名称> to <新名称>                 重命名别名
  ral rm <名称>[, ...]                     删除别名
  ral list                               显示所有别名
  ral info <名称> [--edit]                 显示别名详情（--edit：将编辑命令复制到剪贴板）
  ral cls                                清除所有别名（需确认）
  ral export --all <名称>                  将所有别名导出到 <名称>.ntc.ral
  ral export --select <名称>               选择要导出的别名
  ral import <文件>                        从 .ntc.ral 文件导入别名
  ral make [名称]                          在当前目录创建别名模板
  ral hintn add|rm|rnm|info|ls           管理命名值列表（--hint-n/--select-n 用）
  run <别名>                               使用 'run' 执行别名
  <别名>                                   直接执行别名
  <别名>(<参数>)                             执行带参数的别名
示例：
    ral add build "cargo build"            # 创建简单别名
    ral add greet(x) "echo Hello $x"       # 创建参数化别名
    ral add v "view --care -t -d ${x:-1}"  # 带默认值的别名
    ral list                               # 显示所有别名
    ral export --all myaliases             # 导出别名
    build                                  # 直接运行别名
    ral hintn add port [8080,5050]         # 命名列表供 #x --hint-n port 使用

查看命令：
  view [<目录|文件|@tp|@tp/文件|@tp/目录/>]      显示目录树或文件内容
  view -s, --size [最小值]                  显示大小；带值如 10KB、1.5MB 时隐藏更小的项
  view -fs, --filesize [最小值]             显示文件大小；带值时隐藏更小的文件
  view -ds, --dirsize [最小值]              显示目录大小；带值时隐藏更小的目录
  view --sort size|char|ext              排序子项（目录仍在前）
  view --head <n>                        仅显示前 n 行树
  view --tail <n>                        仅显示后 n 行树
  view <文件|@tp/文件|@tp/目录/文件> [--head N|--tail N|--betw A:B] 显示文件内容（同 txtf）
  view -f, --file                        仅显示文件（移除目录）
  view -dir, --directory                 仅显示目录（移除文件）
  view -ext, --ext <扩展名...>              仅显示匹配扩展名的树
  view -cp, --copy                       显示树并复制到剪贴板
  view -d, --depth <n>                   使用自定义深度显示树
  view -c, --care                        显示所有文件的树（不忽略）
  view --time, -t                        显示含执行时间的树
  view -p, --path <路径|@tp|@tp/子路径>       显示指定路径或传送点路径的树
示例：
    view                                   # 显示目录树
    view --size                            # 显示带大小的目录树
    view -d 2                              # 显示深度为 2 的目录树
    view -cp                               # 显示目录树并复制到剪贴板
    view --time                            # 显示带执行时间的目录树
    view -p C:\code\project                # 显示指定路径的目录树
    view @web                              # 显示传送点的目录树
    view -s 10MB                           # 仅显示至少 10MB 的文件/目录
    view --sort size --head 20             # 按大小排序并显示前 20 行
    view main.rs --tail 30                 # 显示 main.rs 最后 30 行
    view main.rs --betw 10:20              # 显示 main.rs 第 10-20 行
    view @docs/readme.md                   # 显示传送点中的文件

VIEWF 命令（仅文件）：
  viewf [<目录|@tp|@tp/目录/>]               显示深度 1 的仅文件树
  viewf <文件|@tp/文件|@tp/目录/文件> [--head N|--tail N|--betw A:B] 显示文件内容（同 txtf）
  viewf -s, --size [最小值]                 显示文件大小；带值时隐藏更小的文件
  viewf --sort size|char|ext             排序文件项
  viewf -e, --ext <扩展名...>               仅显示匹配扩展名的文件
  viewf -c, --care                       计算大小时包含所有项
  viewf -t, --time                       显示执行时间
  viewf -cp, --copy                      复制文件列表到剪贴板
示例：
    viewf                                  # 列出当前目录中的文件
    viewf src                              # 列出 src 目录中的文件
    viewf -e rs,txt --sort size            # 按扩展名筛选并按大小排序
    viewf @docs/readme.md --head 20        # 显示传送点文件

搜索命令：
  gs <模式> [-p <glob>] [-s [line|path|size]] [-d <n>] [-l <n>] [-i] 搜索文件内容（简单grep）
  gs -i <模式> [-d <n>]                    交互式grep（每页10条，Enter打开）
  help.search.qur
  fs <模式> [-d <n>]                       按名称搜索文件（模糊匹配）
  ds <模式> [-d <n>]                       按名称搜索目录
  locate <模式> [-d <n>]                   同时搜索文件和目录
  fsc <模式> [-d <n>]                      搜索文件，选择后显示并可选择复制
  cmd | gs <模式>                          搜索管道输入的内容（也支持 qur -s <模式>）
示例：
    gs fn main                             # 在文件中搜索 'fn main'
    gs -i config                           # 交互式搜索结果
    fs *.rs                                # 查找 .rs 文件
    ds src                                 # 查找名为 'src' 的目录
    locate README                          # 搜索文件与目录中的 'README'
    qur *.rs -s "TODO" -dp                 # query glob + 类似 grep 的显示
    gs TODO < app.log                      # 搜索管道/重定向输入的内容
    gs error\|warning                      # 或搜索：匹配任意一个词 (a\|b)

系统与网络命令：
  sys, top                               实时系统监视器（CPU、内存、磁盘、进程）

    sys                                    # 显示系统监视器
